# Logo panitia lomba

Taruh file PNG resmi dari panitia di folder ini dengan nama persis berikut
(dibaca oleh `src/components/LogoPanitia.tsx`):

- `dikti-saintek.png`
- `unpatti.png`
- `forkom.png`
- `forkom-2026.png`

Kalau salah satu file belum ada, aplikasi menampilkan kotak placeholder abu-abu
bertuliskan nama logo — tidak error. Ganti nama file di `LogoPanitia.tsx` bila
panitia memakai nama/logo berbeda.

Rekomendasi: PNG transparan, tinggi minimal ~120 px.
